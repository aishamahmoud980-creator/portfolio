About me

I'm a Computer Science student at the Arab Academy for Science, Technology & Maritime Transport, now in my third year, and I work on both sides of the screen: the web and games.

On the web that means HTML, CSS and JavaScript for interfaces, Angular for larger single-page apps, and Flutter when a client needs Android and iOS from one codebase. On the game side I have built a 2D browser game in HTML and a 3D game in Unity with C# — movement, collisions, scoring, levels, and a build someone can actually play.

Underneath all of it is the foundation: C, C++, Java and Python, plus data structures, algorithms and object-oriented design. That is what lets me open an unfamiliar codebase, find the bug, and fix it instead of guessing.

What clients tend to notice: I ask questions before I write code, I send progress you can click on rather than status updates, and I finish what I start.
